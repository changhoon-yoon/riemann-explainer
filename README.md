# 리만가설, 도대체 뭐가 풀린 걸까?

중학생도 따라올 수 있게 만든 13단계 애니메이션 설명 페이지예요.

👉 **바로 보기: https://changhoon-yoon.github.io/riemann-explainer/**

2026년 11월 20일 "AI(Claude)와 수학자가 리만가설을 풀었다"는 소식이 나왔어요. 이 페이지는 다음을 차례로 설명해요.

1. 소수와 소수 개수 세기
2. 제타 함수와 영점
3. "영점이 1/2 위에 있다"는 게 무슨 뜻인지, 왜 하필 1/2인지
4. 167년 동안 어디까지 왔는지 (41.6% → 67.2% → 전부)
5. 이번 증명이 무엇을 검증받았고 무엇이 아직 남았는지

## 사용법

- 「다음 →」 버튼이나 키보드 ← → 로 넘겨요.
- 「▶ 자동 재생」을 누르면 끝까지 알아서 넘어가요.
- 그래프에 마우스를 올리면 숫자가 보여요.
- 인터넷 연결 없이 `index.html` 파일 하나만 열어도 동작해요.
